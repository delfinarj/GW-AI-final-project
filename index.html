Masks for Skipper-CCD images that do not depend on the sensor

Can the masks that remove readout defects, material defects and unwanted physics from a Skipper-CCD image be written so that they work on a sensor they were never tuned on?

D. Rodriguez Juiz and F. Pérez · final project · every number on these pages is read from a result file, and every result file carries a sidecar with the code, the inputs and the seed that made it.

  • The report

    The question, the six masks in their fixed and adaptive forms, what was measured on three simulated sensors and on the public SENSEI data release, how each result was checked, and what is still wrong with it.

  • The same report as a PDF

    Printed from the page itself, so no number is retyped.

  • PROVENANCE.md

    Where every input came from, what was written from scratch and what was called from a library, every choice that had a defensible alternative, how each result was checked, and every error found along the way.
